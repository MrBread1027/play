# 4D 号码分析器（Magnum / Da Ma Cai / Sports Toto）

用最近十年的开奖资料，统计每个号码出现的次数，选出推荐号码，
并显示**真实的中奖概率**和**历史回测结果**。

> 每期开奖都是独立随机的。推荐号码只是"过去出现较多"的号码，
> 不会提高中奖概率。App 里的回测数据可以验证这一点。

## 文件结构

```
python/app.py          Python 版（电脑界面 + 命令行）
python/lotto/fetch.py  抓取开奖资料
python/lotto/analyze.py 统计、推荐、概率、回测
web/                   手机/电脑网页 App（可装到 iPhone / Android 主画面）
data/draws.json        十年开奖资料（自动维护）
.github/workflows/     每天自动更新 + 发布网页 App
```

只需要 Python 3.9 以上，**不用安装任何套件**。

## Python 版

```bash
python python/app.py            # 打开电脑版界面，按「更新资料」
python python/app.py update     # 只更新资料（命令行）
python python/app.py serve      # 在本机开网页版，手机连同一个 WiFi 就能看
```

第一次更新要下载十年资料，约 30-40 分钟，之后每次只下载新的开奖，几秒钟就好。

## 手机 App（iPhone 和 Android 都能用）

网页 App 需要放在网上，手机才能随时打开。推荐用免费的 GitHub Pages：

1. 在 GitHub 新建一个 repository，把整个文件夹上传
2. Settings → Pages → Source 选 **GitHub Actions**
3. Actions 页面执行一次 `update-and-deploy`
4. 完成后会得到网址，例如 `https://你的名字.github.io/lottery4d/`
5. **iPhone**：用 Safari 打开网址 → 分享 → 「添加到主屏幕」
   **Android**：用 Chrome 打开 → 选单 → 「安装应用」

之后每天马来西亚时间晚上 9 点会自动抓新资料、更新 App。

## 推荐方法和概率

- **推荐号码**：分数 = 十年出现次数 + 2 × 近半年出现次数，取前 4
- **位数频率组合**：千、百、十、个位各取最常出现的数字
- **Toto 6/50·55·58**：热号 = 出现最多的 6 个；冷热混合 = 4 个热号 + 2 个最久没开的
- **真实概率**（RM1 Big）：头奖 1/10,000；任何奖 23/10,000；iBox 按组合数相乘
- **Jackpot**：两个号码同时中头三奖中的任意两个，约 1/16,665,000
- **回测**：最近 150 期，每期只用当时之前的资料选号，再对比随机选号的命中率

## 「计算」tab 的 8 种选号方式

选公司和计算方式，按「计算」后给出 3 个号码（程序在 `python/lotto/methods.py`）：

| 方式 | 怎么算 |
|---|---|
| 热号法 | 十年出现最多（近半年加倍） |
| 冷号法 | 以前常开、但最久没出现 |
| 位数频率法 | 每个位置最常见的数字组合 |
| 对数法（阴阳数） | 上期头三奖每位换对数 0↔5 1↔6 2↔7 3↔8 4↔9 |
| 拖号法 | 历史上某数字开出后，下期同位置最常跟的数字 |
| 3D 热门尾数法 | 最常开的后三位 + 最常搭配的千位 |
| 和值法 | 最常见的四位数字总和里，出现最多的号码 |
| 头奖加减公式 | 上期头奖每位 +1、-1、前后倒转 |

## Prediction Engine V2（`python/lotto/engine.py`）

每家公司的推荐号码由 V2 引擎计算，对全部 10,000 个号码打分：

| 特征 | 权重 |
|---|---|
| 长期频率（十年） | 20% |
| 近期频率（近 78 期） | 20% |
| 位置频率（千/百/十/个位） | 15% |
| 数字对 Pair（6 种位置组合） | 15% |
| 遗漏值 Gap | 10% |
| 模式 Pattern（ABCD/AABC/AABB/AAAB） | 10% |
| 机器学习（在线逻辑回归） | 10% |

- **过滤**：数字和在历史 2%–98% 范围外、AAAA、全奇/全偶且全大/全小
- **评分**：标准分，平均号码 = 50，每高一个标准差 +10
- **Walk-forward 回测**：第 150 期起，每期只用之前的资料打分再对照结果，报告 Top 4/10/20/50/100 命中数、头奖次数、p 值
- **校准**：显示推荐号码在回测中的实际命中率和 95% 区间，而不是模型自称的 confidence

## 最新成绩（实时）

- **电脑版**：「最新成绩」tab。勾选「开奖时间自动更新」后，每晚 7-9 点每分钟看一次实时成绩（开奖中会显示「● 开奖中」），每 5 分钟完整更新一次。
- **手机 App**：「成绩」tab。GitHub 在晚上 7-9 点每 10 分钟抓一次（`web/live.json`），App 打开时每分钟检查一次。GitHub 的排程可能延迟几分钟。
- 每家公司下面有「开奖前 V2 推荐对奖」，用开奖前算出的 4 个推荐号码对照这一期，显示中了什么奖或 iBox。
- 实时成绩来自 4dmoon.com 的 `feedwest.json`；开奖完成后才写进历史资料（`fetch.complete()` 检查头三奖、特别奖、安慰奖都齐全）。
